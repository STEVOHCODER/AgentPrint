AgentPrint 1.0.0 — first-run checklist (2 minutes)
================================================

1. Double-click "Start-Agent-Console" and enter:
     Backend URL : your cloud URL (or http://localhost:3000 for LAN mode)
     Office code : from your admin page (e.g. DEMO-2387)
     Printer ID  : e.g. reception
2. For Word / Excel / PowerPoint auto-print, install free LibreOffice:
     https://www.libreoffice.org/download/download/
   (PDF and images print with nothing extra to install.)
3. Open the agent dashboard http://localhost:39500/ and print the QR.
   Stick it on the printer. Guests scan -> upload -> papers come out.
4. After this first run, close the console: the agent now starts
   automatically with Windows (hidden, no clicks needed).

No Node.js install needed — the runtime is bundled in this folder.
